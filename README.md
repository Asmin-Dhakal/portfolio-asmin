# asmin.dev — Portfolio

Personal portfolio of **Asmin Dhakal**, full-stack developer (web, Flutter mobile, deploy & hosting).
Built with Next.js 16, Tailwind CSS v4, Framer Motion and Lenis.

## Develop

```bash
npm install
npm run dev     # http://localhost:3000
```

> Note: on WSL, install and run from a Linux path (e.g. `~/portfolio-asmin`) —
> `npm` struggles with atomic renames on Windows-mounted drives (`/mnt/d`).

## Build

```bash
npm run build
npm start
```

## Content

- `data/site.ts` — name, email, GitHub, Fiverr, resume links
- `data/content.ts` — projects, stack, experience
- `public/projects/` — project cover art
- `public/resume.pdf` — resume file
